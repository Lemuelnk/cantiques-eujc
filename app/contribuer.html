Contribuer

Cantiques EUJC est un projet communautaire. Son objectif : offrir à l'Église un recueil numérique fiable, multilingue et accessible à tous.

Il existe 6 façons d'aider, chacune adaptée à un profil différent. Tu n'as pas besoin d'être développeur pour contribuer.

6 façons de contribuer

Développement PWA, admin, worker, Flutter, scripts
Contenu Ajouter, corriger, vérifier les paroles
Traduction Anglais, lingala, swahili, tshiluba, kikongo
Audio Enregistrer ou fournir des liens audio
Administration Valider les signalements, modérer
Financement Soutenir l'infrastructure ou une feature

Comment commencer

1
Lis le guide de contribution

Le fichier CONTRIBUTING.md explique comment fonctionne le projet, les conventions de code et le workflow Git.

2
Choisis ton domaine

Code, contenu, traduction, audio, admin ou financement. Chacun a son guide détaillé.

3
Crée une issue ou une PR

Pour les bugs et propositions : issue. Pour les contributions concrètes : Pull Request.

4
Sois patient

Le projet est maintenu par 1 personne à 2-5h/semaine. Une PR peut mettre quelques semaines à être reviewée.
