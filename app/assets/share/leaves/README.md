# Illustrations feuillage

## Fichiers à fournir
- **leaves-top.png** — Feuillage coin haut (PNG fond transparent)
- **leaves-bottom.png** — Feuillage coin bas (PNG fond transparent)
- **leaves-decoration.png** — Feuillage latéral (optionnel)

## Taille recommandée
- 800x600 minimum, PNG haute résolution
- Fond transparent obligatoire
- Style : feuilles vertes organiques comme la maquette splash

## Utilisation
Intégrés en filigrane subtil (opacité 15-25%) dans les images générées.
