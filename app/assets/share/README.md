# Ressources graphiques — partage Cantiques EUJC

Espace réservé aux ressources officielles à intégrer à la fiche image. Le moteur actuel reste fonctionnel sans assets externes.

À fournir lorsque disponibles :
- `logo-eujc.svg` : logo officiel vectoriel ;
- `logo-eujc-light.svg` et `logo-eujc-dark.svg` : variantes pour fonds foncés/clairs, si nécessaire ;
- `motif-botanique.svg` : motif décoratif transparent facultatif ;
- `app-qr.png` : QR code vers l’URL publique définitive, jamais vers localhost.

Contraintes : conserver les paroles hors des assets et les rendre depuis les données canoniques ; ne pas recolorer arbitrairement le logo ; ne pas fournir de QR provisoire. Les quatre palettes actuelles sont dessinées par CSS/Canvas et ne nécessitent pas d’images de fond. Aucun asset fictif n’est ajouté ici : ce dossier attend les originaux fournis par le propriétaire du projet.
