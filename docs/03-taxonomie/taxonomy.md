# Cantiques EUJC — Taxonomie

## 1. Principe

Deux niveaux sont distingués :
1. la taxonomie de la source EUJC ;
2. la taxonomie retenue pour l'application.

La taxonomie source n'est pas réécrite dans les données RAW.

# 5. Hors application

Les éléments « Divers / Général » du site ne sont pas exposés comme catégories de l'application :
- Dictionnaire biblique
- Ne fais pas gaffe !
- Au bon soin de Ngenda

Ils peuvent rester conservés dans les ressources ou données RAW pour la traçabilité.
