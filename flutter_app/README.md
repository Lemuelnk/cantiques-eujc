# Cantiques EUJC - Flutter (Android + iOS)

Application mobile native pour les cantiques EUJC.
Base : PWA existante dans ../app/

## Premier lancement sur PC

git clone https://github.com/Lemuelnk/cantiques-eujc.git
cd cantiques-eujc
git checkout polish
cd flutter_app
flutter create --org com.lnkstudio --project-name cantiques_eujc --platforms=android,ios .
flutter pub get
flutter run
